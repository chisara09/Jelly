# Documentation Overview

Use this folder to quickly find the references that matter for the current development cycle while keeping historical notes out of the way.

- `current/`
  - Short lists and active checklists that guide what is happening right now.
  - Start here for open bugs, sprint focus, and the lightweight dev guide.
- `archive/`
  - Detailed background material, including the full requirements, backend plans, audits, and historical update logs.
  - `archive/instructions/` contains the original build and backend documentation.
  - `archive/updates/` keeps screen-by-screen write-ups and feature histories.

When you add new docs, place long-form research or finished work in `archive/` and keep living documents in `current/` so the workspace stays easy to scan.
