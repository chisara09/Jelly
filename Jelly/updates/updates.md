# App Screens

## Authentication Screens
1. **WelcomeView** - Initial landing screen
2. **LoginView** - User login screen
3. **SignUpView** - User registration screen

## Main App Screens
4. **HomeView** - Main dashboard/home screen
5. **ProfileView** - Current user's profile screen
6. **FindPlayersView** - Screen to discover and connect with nearby players
7. **LeaderboardView** - Rankings and leaderboard display
8. **ChatView** - Messaging/chat interface
9. **GameDetailsView** - Detailed view of a specific game
10. **NewChallengeView** - Screen to create/initiate a new game challenge
11. **ConfirmScoreView** - Screen to confirm and submit game scores
12. **OtherPlayerProfileView** - View another player's profile

**Total: 12 Screens**
